# Projet Hercules - Défi 3 : Planification Intégrée pour un Réseau de Drones Urbains

## Description
Ce projet concerne la conception et l'optimisation d'une flotte de drones pour des livraisons urbaines à Lille. Les drones doivent naviguer efficacement dans un environnement urbain dense, en optimisant l'énergie et les itinéraires.

## Structure du Projet
- **Jalon1_CAO_Drones** : Modélisation CAO des drones avec capteurs (20%)
- **Jalon2_Simulation_Energie** : Simulation de l'efficacité énergétique des itinéraires (30%)
- **Jalon3_Algorithme_Planification** : Développement d'un algorithme de planification optimale (30%)
- **Jalon4_Bonus_Meteo** : Ajustement en temps réel selon la météo (10%)
- **Doc/** : Documentation et roadmap
